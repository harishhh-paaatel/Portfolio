# Harish Patel Portfolio

A futuristic, premium developer portfolio built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, GSAP, React Three Fiber, and Lenis smooth scrolling.

## Features

- Cinematic landing page with animated hero text
- Glassmorphism cards, floating gradients, and neon glow shadows
- 3D interactive developer illustration using React Three Fiber
- Scroll progress indicator and active nav highlighting
- Premium responsive layout for desktop, tablet, and mobile
- Smooth page animations, scroll-triggered reveals, and hover effects
- Projects, skills, experience, services, testimonials, and contact sections
- Production-ready SEO metadata

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Three.js / React Three Fiber
- Lenis smooth scrolling
- Lucide React icons

## Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is ready for Vercel deployment.

1. Push the repository to GitHub.
2. Import the project into Vercel.
3. Set the root directory to the repository root.
4. Vercel automatically detects Next.js and deploys.

## Project Structure

- `app/` — Next.js App Router pages and layouts
- `components/` — Reusable UI sections and animation components
- `components/ui/` — Shadcn-style UI primitives
- `lib/` — data, utility helpers, and animations
- `styles/` — global Tailwind CSS styles
